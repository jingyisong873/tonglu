# 运行一个例子

用桌面教学机器人比较新加坡、德国、美国三条市场路径。

1. 启动后确认顶部显示“示例回放 · 不调用模型”。价格、成本和销量是可修改的演示假设。
2. 打开“情景与预测”，将一个市场的年销量减半，观察经营贡献、盈亏平衡与保守情景的变化。
3. 保存并点击“开始研究”。固定样例会经过摘录检查、计算和版本保存。
4. 打开“资料与知识”，展开摘录，查看原文和“固定虚构样例”标记。
5. 打开“执行与反馈”，添加待验证行动。记录反馈后保存，旧研究会标记为对应旧输入。
6. 导出 Markdown 或 JSON，核对假设、计算和来源。重新研究会创建新版本。

[省际渠道](../examples/regional-channels.md)比较国内分销路径；[个人服务](../examples/personal-service.md)比较两份互斥的拟议订单。

## 真实研究

按[配置说明](configuration.md)接入模型服务后，使用公开或已获授权的资料开始研究。逐条核对来源日期、产品范围、原产地和准入条件。保存实际反馈；示例销量和离散情景仍属于假设，不能替代需求证据。
