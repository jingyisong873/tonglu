First public source release of Tonglu, a local workspace for market research and scenario comparison.

- React interface, local SQLite storage and searchable source evidence.
- Offline fixture replay with three synthetic examples; no model key required.
- Optional DeepSeek research with source checks, input snapshots and resumable stages.
- Deterministic contribution, break-even and scenario calculations for ongoing operations and one-off transactions.
- Loopback-only server, request validation, revision checks, concurrent-run protection and bounded research streaming.

Requires Node.js 24. Unpack the source archive, run `npm ci` and `npm run dev`, then open `http://127.0.0.1:5173`.

The release workflow requires tests, type checking, production builds, example generation and dependency checks on Linux and Windows before publishing. `SHA256SUMS` covers both attached source archives.

Live model quality and customer outcomes have not been independently evaluated. This version is intended for a single user on a trusted local machine; it does not include public-service authentication or multi-user isolation.
