# Tonglu v0.2.0

Research now runs independently of its browser connection while the local service remains running.

- Reload or reopen a project to observe the same active research task.
- Stop a task explicitly, keep completed stages, and resume it later.
- Restart the service without silently initiating model requests; interrupted tasks are marked paused.
- Keep one active task per project and save completed results together with searchable facts.
- Preserve errors when a new run fails, rather than displaying the previous run as a new success.

The source distribution remains MIT-licensed and local to one user. The existing nine-minute execution limit is unchanged. Market, country and company relationship research is documented as the broader product direction; the current analytical workflow remains market and transaction research.

## Run

Requires Node.js 24:

```sh
npm ci
npm run dev
```

For a production build on your computer:

```sh
npm run build
npm start
```

Existing SQLite workspaces are supported. Stop the previous service and back up the complete `.tonglu` directory before replacing source files. Use your own `.env` for live model access; the archive contains no credentials or research database.

## Verification

The automated suite includes 51 tests, with type checking and a production build. Browser interaction checks cover reload, close/reopen, stop/resume, stream failure/reconnection, and a rejected new run after an earlier success. These checks use synthetic fixture research; they do not establish live-source accuracy or business outcomes.
