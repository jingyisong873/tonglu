# 通路 · 市场与交易推演

产品工作名：通路（Tonglu）。名称表达连接供给与需求的交易路径。它不以某一国家、跨境方向或某类参与者命名。此处确定的是产品工作名，未进行商标可注册性审查。

**口号：看清需求，算清代价，找到可行的交易路径。**

**摘要：** 通路是面向企业、小团队和独立经营者的 AI 市场与交易推演工作台。围绕一项产品或服务，比较不同地区、客户与渠道的交易方案，把公开资料、业务假设和实际反馈组织成可追溯的证据、可重算的经营情景与可执行的验证行动，帮助使用者判断先做什么、需要满足哪些条件，以及什么变化会改变选择。

**宗旨：** 在投入之前看清交易成立的条件，减少资料缺口、模糊假设和错误比较造成的试错。

**愿景：** 让专业的市场与交易判断成为小团队和个人也能使用的能力。

## 统一的决策对象

一项决策由供给方、购买者、交易对象、市场环境、交易路径、经营条件和成功标准组成。供给方和购买者可以是企业、机构或个人；市场环境包括国家、省市和细分市场；路径包括触达、成交、交付、验收、结算与责任。

国家与国家、企业与国家、公司与公司不是同一层级的实体关系：国家通常是制度和市场范围，企业或个人才是交易参与者；政府采购时，采购机构是具体购买者。不能把国家 GDP 当成某公司的收入，把省份的规模当成个人需求，也不能因为两个方案在同一国家就把它们合并。

| 用户场景 | 共同结构中的表达 | 需要分别研究的机制 |
|---|---|---|
| 国家到国家 | 具体产品由一地供给，面向另一地客户 | 需求、渠道、原产地、跨境交付、进入条件 |
| 省份到省份 | 国内区域市场与履约路径 | 客群、物流、服务半径、采购、地方经营条件 |
| 企业到国家 | 企业对目标市场买家 | 客户细分、竞品、分销与经营条件 |
| 企业到企业 | 一项产品、合同或项目 | 采购流程、报价、交付、验收、账期 |
| 个人到个人 | 具体服务或单次交易 | 工作范围、修改次数、质量、支付和责任 |
| 市场到市场 | 地域或客户群的拓展 | 偏好差异、适配成本、替代品与渠道 |

国家贸易总量、产业转移、政策冲击的宏观预测是另一类决策任务，需要产品或行业级双边贸易数据、政策变量与经过验证的模型。目前没有实现这一能力，不能把微观经营试算改称国家贸易预测。

## 应当建立的区分度

通路的基本交付物是一项可以检查的选择：建议、支持它的事实、决定结果的假设、改变建议的条件、下一步取得证据的方法。

大范围检索本身不足以形成区分度。ITC Trade Map 已提供按国家和产品查看出口表现、国际需求、替代市场和竞争信息的工具。通路应重点做好具体使用者的交易条件、不同路径的可比计算、未知条件的验证顺序与实际反馈，而不是声称拥有更广的数据或优于所有研究产品。

参考：[ITC Trade Map 产品介绍](https://www.trademap.org/stAbout_tradeMap.aspx)、[UN Comtrade](https://comtrade.un.org/)。这些是对已有能力的参照，当前产品没有宣称已经接入它们。

## 通用性与垂直深度

复用的是问题表示、证据规则、计算接口、版本与反馈机制。具体模型由业务机制选择：

- 持续经营：年基准销量、进入等待、爬坡、固定支出与增长假设。
- 一次性交易：本次数量在交付月计入一次，不重复产生销量；情景改变交付延迟、售价和成本。
- 互斥方案：同一资源或订单的多个备选，最多选择一条。
- 独立方案：确认无重复需求或资源占用后才可组合；共享成本和相互影响尚未建模。
- 未来行业模型：订阅留存、用量服务成本与质量、实物产能与库存、项目工时与变更、账期与现金流，需分别完善。

第一批真实验证仍可围绕教学机器人和 AI 服务的市场研究展开。通用结构使方法可以迁移；有明确产品、真实客户材料和可复核结果的案例建立深度。

## 当前完成与剩余差距

本次已实现：参与方与市场分离；同国内的多路径；区域与客户范围；交付、结算、成功标准；一次性交易引擎；互斥与独立选择；五种统一计价币种；两类新增示例；研究上下文、来源策略、导出与历史项目兼容。

币种切换只声明共同计价单位，不自动兑换已有金额。当前金额字段 `budgetUSD` 是兼容旧项目的内部存储名，其实际计价单位由 `currency` 声明；旧项目默认 USD。

后续实质差距：产品／行业／地区数据接入；真实案例标注与评测；每一行业的经济和预测模型；现金、账期、产能与共享资源约束；关键变量变化到受影响结论的自动更新；长期预测校准。当前研究执行需要页面保持连接，不包含真实撮合、签约、收付款或履约。

成功需要业务证据：关键条件是否查对，选择能否被解释，新证据出现后是否合理修正，真实验证是否减少无效投入。工程通过与上线可以证明系统可运行，不能直接证明商业效果、预测优势或候选人的个人贡献。
