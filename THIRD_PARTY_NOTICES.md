# Third-party components

This source release uses React / React DOM, Vite and its React plugin, TypeScript, Zod, Lucide React and the corresponding type packages. Their copyright notices and licenses are distributed with the installed packages in `node_modules`; they are not relicensed by this project's MIT license. Lucide includes icons with ISC and inherited MIT notices; retain the notices supplied in that package when redistributing it.

The package lock records resolved dependency versions. This archive excludes downloaded dependency source and the original hosting platform's infrastructure, authentication adapters and build tooling.

DeepSeek is an external model and tool provider. API access follows its service terms and the caller's account permissions. World Bank observations retain their source and retrieval metadata. Retrieved web content and user documents remain subject to their own rights; no external webpages or live workspace data are bundled in the synthetic examples.
